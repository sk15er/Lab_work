### Lab A: Fundamentals of Programming Lab (OSU-107-V)
Languages for every program: **C, C++, Python**.
 
1. Print "HELLO"
2. Add two numbers
3. Calculate simple interest
4. Calculate absolute value of a number
5. Swap the values of two numbers
6. Find gross salary of a person
7. Check if a number is even or odd
8. Find greatest of three numbers
9. Find grade of a student given his marks
10. Find divisor or factorial of a given number
11. Print the Fibonacci series
12. Print first ten natural numbers
13. Print the reverse of a number
14. Print the multiplication table of a given number
15. Find grade of a list of students given their marks
16. Function `power(a, b)` to calculate a raised to b
17. Print a 1-D array of 10 numbers in reverse order

### Lab B: Calculus Lab (MTU-103-V)
The syllabus says "MATLAB/Mathematica etc.", so give every program in **MATLAB (runs as GNU Octave)** and **Python (NumPy / SymPy / Matplotlib)**.
 
1. Basic matrix operations: addition, multiplication, inverse, transpose, determinant, submatrix, compatibility, element-wise multiplication
2. Plot graphs of `cx`, `[x]`, `|ax+b|`, `sin(ax+b)`, `cos(ax+b)`, `|sin(ax+b)|`, `|cos(ax+b)|`, `e^(ax+b)`, `log(ax+b)`, and show the effect of `a` and `b`
3. Plot polynomials of degree 4 and 5 with their first and second derivatives, and analyse the graphs
4. Compute limits and differentiation of functions
5. Taylor series expansion of functions
6. Sketch curves along with their asymptotes
7. Sketch parametric curves

Where a point has several functions or cases (for example item 2 lists nine functions, item 1 lists eight operations), make each one its own small example inside the same program page, so students can run them one at a time.
